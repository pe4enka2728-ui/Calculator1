В ходе практической работы №3 создали приложение «Калькулятор» в Android Studio на языке Java.
Разработали XML-разметку с использованием LinearLayout и GridLayout. Добавили поля EditText для ввода двух чисел, TextView для отображения операции и результата, а также кнопки вычислений.
Реализовали сложение, вычитание, умножение, деление и очистку полей. Обработку нажатий организовали через onClick() с использованием if / else. Добавили проверку корректности ввода.
Расширили калькулятор кнопками извлечения корня и возведения в степень. Второе число задаёт показатель корня или степень. Добавили проверку допустимости вычислений.
Изменили расположение элементов интерфейса: поля ввода разместили над кнопками с отступом. Настроили размеры и оформление кнопок.
